### 4.2 中文环境下英文残留（i18n 缺键，必修）

浏览器实际渲染为 `▸ AI generation — Source: panel`。原因：`DOM_TRANSLATIONS` 映射表**没有这些键**，`t()` 回退英文：

```js
function t(text) { return isChineseLocale() ? (DOM_TRANSLATIONS[text] || text) : text; }
// 两处调用：
//   make(..., t("AI generation"))            ← AI 区块 summary
//   aiSummary.textContent = `${t("AI generation")} — ${t("Source")}: ${t(source)}`;
```

需补键（`DOM_TRANSLATIONS` 定义在 JS 前部，搜 `"Audio": "音频"` 即到）：

- `"AI generation": "AI 生成"`、`"Source": "来源"`
- source 取值为 `panel/ai/offline/format`，`t(source)` 同样缺键 → 建议改为查 `locales/zh/nodeDefs.json` 中 `prompt_source` 选项的中文标签（后端已有：界面生成/AI 生成/离线模板/格式整理 之类，**以后端 nodeDefs 为准**），或在前端加映射 `"panel": "界面生成"` 等，两边必须一致。
- 顺带全检：对 DOM 面板所有可见文案做一遍中文环境截图，凡英文残留（按钮/占位符/toast）都补键。`locales/zh/main.json` 仅 82 字节，基本没用上——**注意 `t()` 只查 `DOM_TRANSLATIONS`，与 locales/*.json 无关**，别改错地方。

### Playwright 取证片段（可直接用）

```js
// 面板 bg 色值普查
const aio = app.graph._nodes.find(n => n.type === 'MiniMaxH3IntegrationRH');
const el = aio.widgets.find(w => w.name === 'gh_h3_panel').element;
const counts = {};
el.querySelectorAll('*').forEach(e => {
  if (!e.offsetHeight) return;
  const bg = getComputedStyle(e).backgroundColor;
  counts[bg] = (counts[bg] || 0) + 1;
});
return JSON.stringify(Object.entries(counts).sort((a,b)=>b[1]-a[1]));
```

弹窗同理：先点 ✦（优化器）或 ⚙（裁剪）按钮打开弹窗，把 `el` 换成 `document.querySelector('.ghh3-opt-dialog')` 所在 overlay。
