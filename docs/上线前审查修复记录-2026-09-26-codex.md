## 验证边界

未执行完整 ComfyUI 浏览器操作、GPU 视频生成或 RunningHub 云端请求，不能据此保证实际网关支持 600 秒长连接。

线程取消是协作式的：LLM token/重试等待及引擎作业边界检查信号；若同步 requests 正阻塞等待网络，可能要等当前网络调用返回或读超时（现有单次窗口最高 60 秒），不会强杀 Python 线程。前端立即停止接收结果，服务端在该线程退出前仍占用并发槽位。

历史 ai_api_key 原生 widget 的明文序列化策略不在本轮改动范围；本轮保证的是新增 HTTP 错误出口不泄露凭据，以及既有 optimizer 状态脱敏路径继续保留。
