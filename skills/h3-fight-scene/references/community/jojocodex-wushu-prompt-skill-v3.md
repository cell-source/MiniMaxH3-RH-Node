## 三、核心战斗基础规则

### 1. 近身缠斗规则
- 允许短暂近身、抱摔、过肩摔、接腿摔、贴山靠突进
- 禁止长期贴身黏连、持续搂抱、夹颈锁身、地面锁技、地面连续捶打
- 所有摔技、近身动作**一次性完成**，结束立刻分离拉开攻防距离
- 铁山靠为短促突进招式，接触瞬间即刻分离

### 2. 防守轮换规则
- 防守方严格交替：格挡 ⇄ 闪躲，禁止连续两次相同防守动作
- 同一时刻仅单方主动进攻，另一方仅可格挡、闪躲、后撤、受击反馈
- 严禁双人同时防守、同时架拳、互相等待对峙
- 进攻方招式完整收势后再开下一轮，无机械打断

### 3. 连续攻防节奏规则（核心：禁止回合制）

**绝对禁止回合制交换**：你打一下→我打一下→你再来一下的"轮流坐庄"节奏是最大穿帮。真实打斗是**不对称、不轮换、连续施压**的：

**压制方规则（连续攻击）**：
- 连续输出 3~5 招**不停手**：前招收势即后招起势，中间无停顿、无回位、无等待
- 招招追着对手的退路打：对手退左打左、对手格挡上盘就转攻下盘
- 压制期间禁止后撤重整——要么继续施压，要么被反击打断

**防守方规则（连续招架流退）**：
- 被压制时**连续招架流退**：格挡、撤步、招架、滑退交替，全程在动
- 招架动作与脚步同步：每挡一击退半步，绝不站在原地连挡
- 招架中眼睛始终锁定对手，寻找反击空档

**反击时机规则（核心：找准空档才反打，不是轮到你才打）**：
- 旧力已尽新力未生的瞬间（对手连招收势的半拍空档）
- 对手重心压得过前、前脚虚浮的瞬间
- 格挡反弹震动、对手手臂发麻的瞬间
- 抓住空档**一招反打即转入压制**，反打后同样连续施压不给对手喘息

### 4. 器械对战规则（持械必格挡、命中必反馈）

**守方反应硬规则**：凡被刀剑劈砍，守方**必须**做出以下反应之一，绝对禁止站着挨砍：
- **举械格挡**：兵刃相交，火星四溅，双方各震退半步，格挡手臂发麻
- **招架卸力**：斜刃引开来势，劈砍顺刃滑开擦出火花
- **闪避**：撤步、侧闪、下潜，刀锋贴身掠过，断发飘落
- **退避中反击**：格挡退半步立即还一招

**命中反馈硬规则**：凡劈砍命中，受击方**必须有即时可见的反馈**：
- 擦伤：衣料划破开口、皮肤渗出血线、受击部位肌肉绷紧
- 命中：身体受击偏转踉跄、闷哼后仰、持械手臂发麻震颤、兵器险些脱手
- 重创：踉跄跪地、兵器拄地支撑、伤口血迹渗出染红衣料

**兵器物理规则**：
- 兵刃相交必有火星与金属嗡鸣，重劈后双方兵刃短暂僵持角力再弹开
- 兵器不会脱手飞出（除非被明确打落），不会凭空出现/消失
- 劈空（砍空）时兵器顺势带偏重心，收势需要半拍回拉，无瞬间停顿

## 四、分级伤害反馈体系（含身体力学词库）

### Lv1 轻度击打（试探/清招）
肩膀震颤、手臂受压微抖、小步滑移、衣料紧绷、头部微偏、视线不离开对手

### Lv2 中度击打（攻防失衡）
身体踉跄、大步后退 2~3 步、重心失衡单脚后撤、胸腹受击弓背弯腰、呼吸急促、抬手护脸、脚步刮擦地面

### Lv3 重度击打（破防）
大幅度踉跄几乎倒地、单膝触地撑起、撞退至墙边或台角、双臂交叉硬防仍被推动、口喘粗气、汗水甩落

### Lv4 终结超重击飞（核心爽点）
- **击中瞬间**：接触点特写，肌肉与衣料凹陷波动，被击者双脚离地
- **凌空阶段**：身体后仰弓形滞空飞出，四肢失控张开，衣袍与汗水甩出弧线
- **落地阶段**：背部或侧身砸地，侧身连续滚地 2~3 圈滑行，刮出地面痕
- **环境交互**：重重撞上墙体/货架/管道，墙面碎石剥落、尘土炸开、金属管件哐当坠落
- **终态**：瘫软滑落地面，四肢摊开完全失去战斗姿态，仅剩微弱喘息

### Lv4 补充：击飞方向一致性（物理逻辑硬规则）

击飞轨迹**必须沿击打力量的作用线**，禁止乱飞、横向漂移、无依据旋转飞出：

| 击打招式 | 正确击飞方向 |
|---|---|
| 正面重拳/重锤拳命中胸口 | 沿出拳直线向**正后方**凌空飞出 |
| 上勾拳由下至上 | **竖直腾空**后仰坠落 |
| 扫堂腿扫中下盘 | 沿扫击弧线**横向腾空翻转** |
| 侧踹/鞭腿命中躯干 | 沿腿部轴线**向后滑飞**（脚贴体未离地的滑退可用 Lv2-Lv3） |
| 铁山靠肩部撞击 | 沿突进方向**斜向前下方撞出** |

配套要求：
- 进攻方追击沿**同一条作用线**直线贴进，不绕后不换位
- 镜头跟随击飞轨迹（即作用线）全程跟拍
- 环境撞击点（墙/货架/管道）位于击飞延长线的**正方向**上

> 受击身体力学词库（写 [Shot] 时按部位选用）：
> 头部——头猛然偏转、视线甩离对手、汗水甩落
> 躯干——胸口凹陷波动、弓背折体、躯干拧转卸力
> 下肢——脚跟离地、脚尖点地滑移、膝部跪地弹起
> 整体——双脚离地凌空、滞空后仰、连续侧身滚、撞墙滑落

## 招式选用优先级（核心规则：先 LoRA 库内，后 H3 底模原生）

LoRA 只"认识"训练集里出现过的招式词。选词按以下三级优先，效果从强到弱：

### 第一优先：LoRA 高频招式（频次 ≥7，响应最强最稳）
扫堂腿(47)｜缠头裹脑(54)｜格挡卸力(74+)｜弓步(38)｜腾空(32)｜拧腰(32)｜沉肩坠肘(24)｜马步(29)｜纵跃(18)｜过肩摔(17)｜旋身横扫(17)｜腾空侧踹(17)｜后旋踢(16)｜红缨枪(16)｜闪身(14)｜点步(13)｜蓄力(13)｜贴山靠(12)｜擒拿(12)｜扎枪(12)｜直拳(12)｜横扫(12)｜蹬地(12)｜攻防转换(15)｜顺势(18)｜回马枪式反手撩(10)｜撩剑(8)｜劈剑(9)｜鞭腿(7)｜进步(7)

→ 写法：直接用术语，可加高频发力词组合（"拧腰送胯接扫堂腿"）

### 第二优先：LoRA 低频招式（频次 3~6，有效但需上下文加持）
肘击、推掌、接腿摔、云剑、点剑、双飞脚、正蹬、大刀劈砍、双刀交叉格挡、滚翻卸力、下潜、后仰、空中转体、蹬墙借力、半马步、侧身步…

→ 写法：术语 + 一句完整上下文（发力路线 + 受击反馈），例如"下潜规避接腿摔，顺势翻滚卸力"

### 第三优先：H3 底模原生通用动作（LoRA 库外招式）
库外招式（如巴西回旋踢、高位劈腿、侧空翻、膝撞）底模仍能理解，但没有 LoRA 风格强化，动作会偏向 H3 通用风格：

→ 写法：英文动作描述（底模英文理解强）或物理描述，并可"借库"挂靠最近似的高频 tag：
- 巴西回旋踢 → `spinning high roundhouse kick, full rotational body turn`，可写作"巴西回旋踢（转体后旋踢式发力）"借后旋踢响应
- 高位劈腿 → `overhead axe kick`
- 侧空翻 → `side aerial flip`

### 禁用（训练分布外，勿用）
玄幻光效、伤害型剑气刀芒、护体屏障、超自然位移

### 快速判断流程
1. 招式在 LoRA 高频表里？→ 直接写术语 ✅
2. 在低频表里？→ 术语 + 上下文加持 ✅
3. 都不在？→ 英文动作描述 / 物理描述，并借用最近似的高频 tag ⚠️

## 七、时序动作核心规则

- 所有拳脚、摔技、身法拥有**完整独立的起势、发力、击中、收势**流程
- 单招完整结束后自然衔接下一招，节奏流畅无机械断层
- 防守方格挡/闪躲瞬间立刻衔接反击，无原地停顿、无姿态重置
- 重击击飞后，进攻方必须极速贴身追击，不原地观望
- [Shot 3] 结尾：收势定格为**动态定格**（肌肉仍紧绷、衣料仍在飘、呼吸可见），禁止画面冻结

空镜、冻帧、慢动作、画面翻转、无理由抖动、镜头穿模

- 禁止开场对峙、摆姿势、互相凝视、慢速入场

## 十四、人物一致性强化规则（重点章节）

### 1. 人物锚句（最有效的文字手段）
- 开头句后**紧跟一句固定的人物锚句**：发色+发型+服装+体型+兵器五要素，**逐字固定、全篇一字不差、每条视频重复使用**
- 正确示例：`黑发束马尾、黑色紧身武服、腰束红带、体格精悍的高挑武者`
- 错误示范：每条视频换不同措辞描述同一个人（"黑衣武者"/"暗色服装男子"混用 = 每次生成不同人）
- 同一视频内三个 Shot 的人物描述**必须逐字一致**，不许换词

### 2. 首帧定妆照 i2v（效果最强的手段）
- 用固定人物**定妆照**作为视频第一帧，走 FL2VA 首帧图生视频（i2v）模式
- 人物从定妆照"动起来"，身份一致性远优于纯文生
- 每条视频同一张定妆照开头 → 跨视频人物也统一
- 配合仓库内"多参考双采打斗工作流"使用

### 3. 镜头纪律（快动作防崩脸）
- 翻滚/击飞/高速转身段落保持**中景以上**，禁止滚动瞬间推脸部特写
- 滚地卸力一律用**侧身滚、背部朝镜头**（避免面部剧烈旋转导致人物变相）
- 每个 Shot 结尾给一个**站定/定格姿态描述**（如"马步定式、双手抱拳"），作为下一镜的身份锚点

### 4. Seed 纪律
- 同一人物的所有视频使用**同一 seed** + 同一人物锚句 + 同一底模版本
- 换 seed = 换脸，跨视频人物必崩

### 5. 分段策略
- 长视频（362 帧）身份漂移随时间累积，建议 124 帧分段拍摄后期拼接
- 相邻分段使用相同的收尾/开场姿态描述衔接

## 十五、避坑清单

1. 招式宁专勿泛："扫堂腿" ✔ "踢腿" ✘
2. 一个 Shot 只放 1–2 个招式，别堆砌
3. 不要写"静止站立/呆立"——模型学的是连续动作
4. 保留 `non_diegetic_music: None.`
5. 画质/分辨率交给参数，不要写进提示词
6. 滚地卸力一律用**侧身滚、背部朝镜头**——正面翻滚会导致面部剧烈旋转、人物变相崩坏
7. 人物/兵器崩坏 → LoRA 强度降到 0.6–0.8；动作不够武 → 升到 1.1
8. 人物不一致 → 检查人物锚句是否逐字一致 + 是否用定妆照 i2v + seed 是否固定
9. **守方站着挨砍无反应** → 检查是否写了守方的格挡/闪避/受击反馈（器械对战必有兵刃相交与命中反馈）
10. 劈砍命中无伤反馈 → 每次命中必须有：踉跄/闷哼/衣破/血线 至少一项
