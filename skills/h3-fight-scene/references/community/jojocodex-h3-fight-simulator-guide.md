# H3 武斗模拟器 · 使用指南

针对文件：`docs/duel-sim/h3-wushu-duel-sim(9.8).html`（单文件 HTML 工具，无需安装，浏览器直接打开）。

一句话定位：**先在本工具里跑一场"AI 对局"（回合制网格打斗结算），再把它自动改写成可直接喂给 MiniMax H3 + wushu_action LoRA 的视频提示词。** 目的不是写故事，而是"先精确结算，再写成连续动作段"。

> 提示：**直接双击用 `file://` 打开即可全自动运行，无需本地服务器，也无需装任何 3D 软件。** 3D 预览的模型默认从 CDN 在线加载（跨域已放行），加载失败会自动回退到内置"白模"，三条路径都能用。仅"AI 润色 / 一句话填卡"这类联网 API 调用在 `file://` 下可能因浏览器跨域限制失败，此时才建议用本地服务器（例如在该目录 `python -m http.server` 后访问 `http://localhost:8000/h3-wushu-duel-sim(9.8).html`）。

## 一、界面总览

顶部标题栏：

- **中文 / English**：界面中英切换（已存配置也会随语言保留）。
- **模拟提示词 / 战斗规则**：编辑成片壳与战斗规则（右下弹窗）。
- **AI润色提示**：编辑"给大模型润色用的系统提示"（右下弹窗）。
- **管理员**：登录后可删除云库条目（账号 `admin`，密码 `h3wushu2026`）。
- **API设置**：配置接口、模型、API Key。
- **润色提示词**：对当前输出手动再做一次 AI 润色。
- **生成后自动润色**：勾选后，生成完自动进入润色，**润色完成前不显示提示词、不允许复制**（窗口显示转圈加载）。

左侧配置卡（从上到下）：

- 生成方式（文生视频 / 多参考图）。
- 一句话设定 + 「AI 填充角色卡和规则」。
- 选用成片提示词壳。
- 对打模式（对打 1v1 / 一打多杂兵 / 一打多英雄）。
- 打斗情景（阵地战 / 擂台战 / 追逐战 / 空战 / 水战 / 自定义）。
- 视频时长、运镜。
- 各自模式的字段区（duelBox / hordeBox / heroesBox）。
- 保存自定义英雄模板区。
- 底部三个按钮：**模拟并生成 H3 提示词**、**复制提示词**、**3D 预览**。
- **3D 预览**：用浏览器内 Three.js 渲染打斗动画，并在画面左上角显示**白膜同步**信息（当前情景、运镜、谁出什么招、命中结果、HP），让你直观对照生成的提示词。**不依赖任何 3D 软件，也不需要本地服务器。** 默认自动从 CDN 加载一个带动画的 GLB 模型（`RobotExpressive`），按模拟动作播放对应剪辑；加载失败或离线时自动回退到内置"白模"（一个连贯的人形骨架 + 命中/格挡/闪避/终结姿态 + 走跑步态）。
  - **用颜色区分角色**：角色 **A 为红色、B 为黄色**（白模与加载的 GLB 模型都会按身份上色，红色/黄色一眼可分）。其余模式里英雄橙、我方绿、敌人红。
  - **角色面对面、贴身打、会跑位**：两名角色会**面向对手**并靠拢到贴身距离打；**全程有脚下碎步/游走**（换步、环绕、逼近/拉开），不会原地站桩；两侧道具是**矮栏杆**不挡视野。每次对打都会分出胜负（残血判胜/指定赢家优先），不会僵持成"死线双负"。
  - **按**最终**提示词做动画（不抢跑）**：3D 白膜会在「最终」提示词（含 AI 润色）真正生成后再自动播放，不会在提示词还没出来/还没润色时就先播完。运镜与提示词共用同一套分镜数据，命中即切"撞击急推"。
  - **运镜是真动、且稳（电影感）**：默认「动态」按战斗剧情走**电影镜头演进（全景建立 → 攻方过肩 → 环绕 → 高潮特写，约 3 次刻意转场）**，段内平滑无抖动；你选具体运镜方式（环绕/推近/过肩/特写/横移/摇臂/刀尖主观/双人近景等）则连续平滑执行，命中才切"撞击急推"。已去掉手持随机抖动。
  - **可选：AI 控制运镜（真正"接入大语言模型控制"）**：在 3D 面板勾选「AI 控制运镜」后，程序会把**最后一次（含润色）提示词 + 回合节拍表**发给大模型，让它在合法焦段列表里排出一份 JSON 镜头时间轴（哪一秒用 wide/os/crash/orbit/…、以谁为主），3D 按这份时间轴运镜；失败或没 Key 会自动回退到"智能运镜"。可点「重排镜头」重新生成。
  - **可视化预演编辑器（可编辑镜头表）**：点 3D 面板的「可视化编辑」打开独立编辑页——上面是 3D 视口（实时动画），下面是**可编辑镜头表**：每个镜头可改「镜头类型」（环绕/过肩/特写/撞击/全景/横移/摇臂/刀尖主观/双人近景…）和「主角色」(A/B)，改完点「应用到场景」实时重演；也可拖动刻度、导出视频/分镜计划。你的改动会成为这些镜头的**覆盖**（镜头表里标"已改"），并写进导出的分镜计划。
  - **换模型**：在"模型"一栏粘贴任意可访问的 `.glb` 地址即可（带 `Punch`/`Death`/`Idle`/`Running` 等动画的最合适）；默认是 CDN 上的 `RobotExpressive`。

右侧面板：

- **共享库**：云端模板/规则/提示/角色卡（投稿、点赞、采用、删除）。
- **后台账**：显示本次对局的逐回合结算（谁出招、距离、结果、双方分数）。
- **H3 提示词**：最终生成的提示词，以及 API 日志。

## 二、五步快速上手

1. **选生成方式**：`文生视频`（外貌写进正文并锁定）或 `多参考图`（正文只写 IMAGE1/2/3，不写外貌）。
2. **选对打模式 + 打斗情景 + 时长 + 运镜**。
3. **配角色卡**：可选内置模板，或点「AI 填充角色卡」用一句话生成，或手动填。每个角色需设：武力等级、性格风格、持械、普攻、四类招式（攻击/法术/移动/防守）、防守参数。
4. **点「模拟并生成 H3 提示词」**：右侧「后台账」先出结算，然后「H3 提示词」生成。
5. **取结果**：未开自动润色 → 直接显示并「复制提示词」；开了自动润色 → 等转圈结束、显示润色稿后再复制。

## 三、打斗情景（本次新加）

在「对打模式」下方选择，共 5 种 + 自定义：

| 情景 | 特点 | 默认场景 | 建议运镜 |
|---|---|---|---|
| 阵地战 | 依托石墙/木箱/断柱掩体争夺，重走位与利用遮挡 | 废墟长街 | 全景 |
| 擂台战 | 有边界栏杆，退到边缘即险，正面硬碰 | 高台擂台 | 半环绕 |
| 追逐战 | 一追一逃，距离拉近又拉开，全程运动镜头 | 长街连屋顶 | 追击侧后跟 |
| 空战 | 空中腾挪，借风/踏空/御器，纵向高度与俯冲拉升 | 峡谷高空 | 摇臂升降 |
| 水战 | 湿滑地面，借水势浪花作遮掩，重心与平衡 | 江面木桥 | 低机位 |
| 自定义 | 自己写场景描述 | — | 你自由选 |

- 选择情景会**自动填该情景的默认场景**、并把**建议运镜**切过去。只有当前是"上一次自动填的默认场景 / 某个情景的默认场景 / 为空"时才替换；**你手写的场景不会被覆盖**。
- 生成稿会写入 `【情景】…` 规则块，约束该情景的运动类型与镜头：
  - 阵地战：争夺阵地、依托石墙/木箱/断柱掩体、攻防转换。
  - 擂台战：有边界与栏杆、退到边缘即险、环场俯拍。
  - 追逐战：一追一逃、距离拉近又拉开、全程运动镜头、跨障碍翻屋檐。
  - 空战：纵向高度与速度差、俯冲拉升、借风/踏空/御器、坠重感。
  - 水战：湿滑泥泞、水花、重心与平衡、低机位擦水面。
- 即便所用的成片壳没有预留分镜位置，也会**自动补上分镜与情景/电影级规则**（见第七节），保证不出现"只有角色卡、没有打斗"。
- **AI 润色提示词**里已加入"尊重【情景】的场地与运动类型，不得改成另一种打斗"，防止被润色成标准擂台对打。

## 四、角色卡：等级 / 性格 / 四类招式

### 1. 武力等级（9 级）
自下而上战力递增，且**伤害与范围随等级放大**（等级越高，特效越夸张）：

| 级 | 名称 | 力量系数 | 定位 |
|---|---|---|---|
| 1 | 凡人 | ×1 | 普通人，拳脚寻常 |
| 2 | 好手 | ×1.5 | 练过武艺 |
| 3 | 高手 | ×2 | 一方好手 |
| 4 | 宗师 | ×3 | 开宗立派 |
| 5 | 大宗师 | ×4 | 武林巨擘 |
| 6 | 绝世 | ×6 | 当世绝顶 |
| 7 | 超凡 | ×8 | 超凡入圣 |
| 8 | 神魔 | ×12 | 举手投足撼天地 |
| 9 | 灭世 | ×16 | 挥手移山填海 |

### 2. 性格 / 战斗风格（8 种）
每种性格不只写性格，还会给出「战斗风格」指导语，**并真实影响模拟器的攻守决策**：

| 风格 | 战斗倾向 |
|---|---|
| 嗜血狂杀 | 全程强攻只进不退，无视防守，即便中招仍杀伐 |
| 冷静稳健 | 见招拆招、以守带攻，抓破绽才反打 |
| 铁壁如山 | 以静制动，稳守反击 |
| 疾风迅雷 | 游走缠斗，进如电退如风 |
| 力压千钧 | 一力降十会，刚猛重击压制 |
| 老谋深算 | 后发制人，诱敌反打 |
| 一击必杀 | 藏锋蓄劲，专取破绽一击致命 |
| 冷面寒刀 | 沉冷稳准狠，招招见血 |

生成的提示词里会写入 `性格风格：… 战斗风格：…`（文生与多参考模式都保留性格）。

### 3. 四类招式
每个角色卡招式分四类，且**自动补齐保底数量**（低阶给武道手段，高阶给大能异术）：

- **攻击** ≥4（近身/直击，保留招牌技）
- **法术** ≥4（远程/气劲/异术；1~3 级用飞石/点穴/暗器等武道手段替代，8~9 级为移山填海/星河倒转等）
- **移动** ≥3（走位/腾挪/身法）
- **防守** ≥3（格挡/卸力/护体）

### 4. 特效随等级
命中反馈会随最高等级出现相应特效：低级=衣裂星火尘土；中级=劲风碎石；高级=罡风金光雷电地裂；顶级=天地变色/山崩地裂/虚空裂痕/法相压顶。规则块 `【特效等级】…` 会写入提示词。

### 5. 命中必带反馈
默认规则要求：**命中至少体现一项**——①砍伤（见血）②击打碰撞（身体一顿、动作有重量）③击飞（被打退/撞墙，非布娃娃）；禁止命中无声无息、无因果空击、穿体无伤。此规则已写入三种模式的默认规则、默认成片壳、以及 AI 润色系统提示。

### 6. 电影级打斗 / 变招（同一招也要 18 般变化）
生成的提示词会追加 `【电影级打斗】` 规则块，要求打斗**变化莫测、告别一板一眼**：
- **动势连招**——一招带动量与惯性，移步、转体、重心一气呵成，收势即下一招起势，不停顿不摆姿势。
- **同招多变**——同一招也要换角度、换节奏、换劲力、换轻重、换收尾，或化虚招/骗招、变招为反手、顺势接闪，绝不原样复读。
- **攻守瞬时反转**——格挡/闪避/卸力后立即反击，攻守在一拍内互换，无回合制等待。
- **快慢相间、节奏起伏**——重击前用轻招铺垫蓄力，爆发后留半拍喘息，不匀速不机械。
- **电影动感**——蹬地、转髋、肩肘传力、刀弧、衣摆、尘土、失衡与补救，借环境与道具变化。
- **杜绝一板一眼**——禁止"起势-打-收"固定循环、禁止站桩对招、禁止把打斗写成招式清单。

该规则同时写入**三种模式的成片提示词**、**默认成片壳（{{RULES}}）**与 **AI 润色系统提示**；模拟器出招也已**尽量避免连续复读同一招**。

## 五、生成方式：文生 / 多参考

- **文生视频（t2v）**：提示词写清角色外貌、发型、服装、兵器并锁定；正文不再用 IMAGE 编号。
- **多参考图（ref）**：正文不描写外貌，只写 `IMAGE1=角色A定妆 IMAGE2=角色B定妆 IMAGE3=场景`，分镜只称角色名/编号。**性格与战斗风格仍保留**。

## 六、三种对打模式

### 对打 1v1
- 场地宽/高（格子）、开场间距、A/B 开场分、指定赢家、场景。
- 角色A / 角色B：模板、名称、外貌、完整角色卡。

### 一打多杂兵
- 地图宽/高、怪物数、每怪血、怪物图鉴（可加多种怪物）、怪物模板/外形/持械/攻击距离/攻击伤害、怪物行为（站桩/哨卫/围拢/猎杀）。
- 英雄：模板、名称、场景、外貌、完整角色卡。

### 一打多英雄
- 场地宽/高、我方开场格 X/Y、场景、我方模板/名称/外貌/角色卡、我方开场分。
- 敌方英雄名单：每人可选模板、名称、外貌、开场分、格位置、完整角色卡；点「+ 敌方英雄」继续添加。

## 七、成片壳 / 战斗规则 / AI 润色提示

- **成片提示词壳（tpl）**：决定"输出格式"的模板（含 `{{DURATION}} {{SCENE}} {{CAST}} {{ACTS}} {{SOUND}} {{RULES}} {{LOCK}}` 等占位符）。默认壳已内置。可通过顶部「模拟提示词/战斗规则」编辑或从共享库采用。
- **兜底补全**：如果自定义成片壳里**没有 `{{ACTS}}`（分镜）或 `{{RULES}}` 占位符**，程序会自动把**分镜、`【情景】`、`【电影级打斗】`、`【镜头与节奏】`** 追加到输出末尾，避免出现"只有角色卡、没有打斗"。
- **建议**：自定义壳尽量包含 `integrated_multimodal_description:\n{{ACTS}}`（及 `{{RULES}}`）以控制排版；否则输出会是"壳的内容 + 自动补的部分"连在一起。
- **战斗规则（rule）**：**只作用于战斗模拟**，控制"这场怎么打"；**不再写进生成稿的 `【战斗规则】`**（已从提示词中移除）。识别常见关键词并作用于模拟器：
  - `必须贴身 / 不许拉开` → 强制短兵相接；`拉开 / 保持距离` → 强制游走牵制。
  - `不许用腿 / 禁踢` → 不出腿法；`空手 / 禁用兵器` → 双方赤手。
  - `不许对拼 / 不许硬拼` → 不出现"两招对撞"，化解成一方得手。
  - `点到为止 / 不许打要害` → 命中伤害减轻；`必须命中 / 必须见血` → 显著提高破防/命中概率。
  - `只许格挡 / 以守代攻` → 该方不抢攻、以防守为主。
  - 无法识别的关键词会保持默认行为（不强行解读）。
- **AI 润色系统提示（ai）**：只给大模型润色用，不写进模拟器正文。默认已含"命中必带反馈 / 尊重【情景】/ 电影级变招"等约束。
- **润色规则（硬性要求）**：在「AI润色提示」弹窗里，系统提示词下方新增的输入框。逐条写硬性要求（如"必须保留全部【】块、不许慢动作/冻帧"），润色时**追加给润色模型**，同样不写进 H3 正文。存于 `h3polishRules`。

撰写/采用路径：顶部「模拟提示词/战斗规则」「AI润色提示」，或右侧「共享库」里选分类后采用/投稿。

## 八、自动润色与复制

- 勾选「生成后自动润色」：点「模拟并生成」后，提示词窗口显示**转圈"正在润色提示词…"**，复制按钮变灰；**润色完成前不显示成品、不允许复制**。完成后写入润色稿并恢复复制。
- 不勾选：生成后直接显示、可立即复制。
- 也可随时点「润色提示词」对当前输出手动润色。
- 润色失败（如超时/无 Key/跨域）会回退显示原始稿并恢复复制。
- 「复制提示词」复制当前输出到剪贴板。

## 十二、战斗决策：回归角色性格（攻 / 闪 / 防 三位一体）

> 已去掉"对战记忆/自适应调参"。现在**每一拍怎么打完全由角色自身的性格与战斗风格决定**，模拟器只是把"性格→攻守切换"翻译成节奏：

- **一拍决策**（攻击 / 闪避 / 格挡 不断切换，不再是全程对拼）：
  - **进攻倾向**来自 `aggr`（嗜血·力压·冷面偏高，冷静·老谋·铁壁偏低）。刚防守过（闪/挡）会追加**反击加成**，刚进攻过会**收招/转守**，形成"攻—守—攻"的来回。
  - **防守拍**按性格选**格挡**还是**闪避**：`block`≥`dodge`（铁壁·老谋·冷静）偏格挡，`dodge`高（疾风·一击必杀）偏闪避/游走；且**不会连用同一招**。
  - **未到射程**：逼近 / 游走（绕行）拉开距离，不打空挥。
- **实际对拼结算**（结果有分量、见血、能分出胜负）：
  - 双方同时进攻 → **对拼**（clash，兵刃相交各震半步）；若是**武力悬殊**，偶尔一方直接**压过对方得手**（破防命中）。
  - 一方进攻、一方格挡/闪避 → **格挡**（visible parry，星火+横移）或**闪避**（人离开刃线，刀砍空位）；若**攻方力量明显压过守方所选防守**，这一招**破防得手**（命中/撞墙/终结）。
  - 命中会**累计伤害**，血线见底时判定**终结**（对手跪地/不再对望）——单次伤害有上限，不会满血一下被秒，需要多拍来回才分出胜负。
- **怎么看出性格差异**：嗜血 vs 铁壁 = 更多对拼+格挡；嗜血 vs 疾风 = 对拼+大量闪避游走；冷静 vs 冷静 = 高格挡的缠斗拉锯；力压 vs 铁壁 = 重击屡屡试图破防。
- **不同情景**：阵地/擂台=贴身近战；追逐战=一追一逃（追击者追上就出手、逃跑者被逼到近身才回身）；空战=飞行高度出招；水战=水下换位。

## 十三、用开源导演台做白膜预演（CozyClay / MONOFORM）

> 想得到**成片级 pre-viz**，就用浏览器里的开源"3D 导演台"做白膜预演 + 排运镜 + 导出视频参考，再喂给 MiniMax H3。本工具负责**生成 MiniMax H3 提示词 + 一份分镜/运镜/动作计划**，两边配合。

> ⚠️ **当前状态**：本工具的「3D 白膜预览」已**暂时关闭并隐藏**（生成提示词后不再自动播放，界面也不显示该面板与「3D 预览」按钮）。想恢复：删掉 `h3-wushu-duel-sim(9.8).html` 顶部 `#d3Panel,#btn3d{display:none !important;}` 这条 CSS，并把 JS 里 `schedulePreview` 开头的 `return;` 一行去掉即可。**导出分镜/运镜计划**（`buildPrevizPlan`）与提示词生成不受影响，仍可正常产出。

- **本工具的「导出分镜/运镜计划」**：3D 面板点「导出分镜/运镜计划」，会生成并下载 `previz-plan.json`（结构化：场景、角色、按回合的 `t/dur/shot(焦段)/focus/pose/skill/contact`），同时右下显示**可读分镜表**（`#镜头 时间 谁「招」→结果 | 运镜 xxx / 主 xxx`）。
- **CozyClay**（[GitHub](https://github.com/NomaDamas/CozyClay)）：开源浏览器 pre-viz，能布场景、pose 角色、编排运镜与剪切，再把镜头喂给 AI 视频模型。**通常 `npx` 一条命令即可跑起来**（详见仓库 README）。把上面的分镜计划当导演镜头表，用它建场景/角色后，按 `shot`（对应它的运镜预设）与 `focus`（主角色）打相机关键帧、按 `pose/contact` 摆姿态。
- **MONOFORM · 素形白模预演工作台**（[GitHub](https://github.com/GuiYi-Xi/monoform-previs-studio)）：浏览器 3D 分镜/运镜/pose/关键帧工作台，概念和你的"白膜预演"一致。同样把分镜计划当作镜头表使用。

- **通用工作流**：本工具跑模拟 → 导「分镜/运镜计划」→ 在 CozyClay 或 MONOFORM 里预演白膜 + 排运镜 → 导出视频参考 → 交给 MiniMax H3 生成视频。
- **说明**：计划给的是"导演镜头表"（哪秒什么镜头、以谁为主、什么动作、什么结果），需在你选的导演台里据此建场景、摆姿态、打关键帧；不同工具的导入格式不同，暂不做一键注入其专属 schema（你若指定某一个，我可以再按它的格式做自动导入）。

## 十四、常见问题

- **提示词/润色不出来，一直转**：多半是 `file://` 跨域。用本地服务器打开，或检查 API Key、网络。
- **生成的招式与设定不符**：四类招式是"等级档位 + 兵器 + 性格 + 每卡种子"自动补齐的保底清单；招牌技保留你填的。若要完全个性化，手动增改招式即可。
- **等级/特效/性格没体现**：确认左上选好了角色、等级与性格；生成的 `【角色设定】/【特效等级】/【情景】` 会说明。
- **生成的提示词只有角色卡、没有分镜/打斗**：多半是你用的自定义成片壳里**没有 `{{ACTS}}` 占位符**。现在程序会自动补上分镜与 `【情景】/【电影级打斗】/【镜头与节奏】`；更稳妥的做法是在成片壳中加上 `integrated_multimodal_description:\n{{ACTS}}` 与 `{{RULES}}`。
- **选"追逐战"等情景，但场景文字没变**：现在选择情景会自动换成该情景的默认场景；只有在你已手写场景、且当前不是任何一个情景的默认场景时才不会被覆盖（属于正常保留）。
- **怎么让一场打斗"不全程对拼"**：现在已**去掉记忆/自动调参**，改由**角色性格驱动**攻闪防切换（攻击→闪避/格挡→下一次攻击）。想让节奏更活，就把 A/B 选成不同性格（例如嗜血 vs 疾风、力压 vs 铁壁）；两角都选纯进攻（嗜血/力压）会偏向硬碰硬的对拼，都选纯防守（冷静/铁壁）会偏拉锯——这正体现了风格差异。
- **换人/换性格后打法会变吗**：会。打斗完全由两人的**性格与战斗风格**决定，没有跨场次记忆。你更换性格/招式/等级，这一场的攻守节奏与对拼结果就会跟着变（例如换成疾风就会多闪避游走）。
- **怎么看到"白模/模型"动画**：先点「模拟并生成 H3 提示词」跑一次，等**最终提示词（含 AI 润色）**显示出来后，左下角「3D 预览」会按这一版提示词自动播放（不会抢先跑完）。无需服务器、无需装软件：默认自动加载 CDN 上的带动画模型播放；若没联网或加载失败，自动回退到内置"白模"。**角色 A 红、B 黄**；运镜按你选的「运镜 / 镜头组合」围绕出招方做真实机位变化（环绕、推近拉近、过肩、特写、横移、摇臂等），命中时切"撞击急推"。想要"用大模型按提示词排镜头"，勾选 3D 面板里的「AI 控制运镜」。
- **润色把追逐战改成了擂台对打**：AI 润色系统提示已加入"尊重【情景】"，但仍建议在「AI润色提示」里把情景约束写得更明确。
- **云库删除不了**：先右上角「管理员」登录（admin / h3wushu2026）。
- **配置存哪**：全部在浏览器 `localStorage`（本机），换浏览器/清缓存会丢失；可用「整库上传/导出JSON」备份。
